# 🧶 Stitches by Mona – Crochet & Knitting Website 🧶

This is the frontend client for **Stitches by Mona**, a crochet and knitting business by Monalisa Sabina.  
The site showcases handmade crochet and knit products, brand information, and will include interactive features like a chatbot to assist visitors.

---

## ✨ Features
- Beautiful landing page introducing Stitches by Mona
- Product showcase (crochet and knit items)
- Business information and contact details
- Planned chatbot integration for customer support and learning

---

## 🛠 Tech Stack
- **React** – frontend framework
- **Vite** – fast development build tool
- **CSS** – styling
- **ESLint** – code linting

---

## 🚀 Getting Started
Clone the repository and install dependencies:

```bash
 git clone https://github.com/monalisasabina/Stitches-By-Mona-Frontend-client.git
 cd Stitches-By-Mona-Frontend-client
 npm install
 npm run dev
 ```
